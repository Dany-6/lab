Aim

To analyze the network behavior of malware using Wireshark and identify suspicious
communication such as unusual IP addresses, ports, DNS requests, HTTP traffic and
repeated connections.

Algorithm

1. Start Wireshark and open the malware network-capture (.pcap/.pcapng).

2. Observe the network packets generated by the infected system.

3. Identify the source IP address of the infected machine.

4. Check the destination IP addresses and ports.

5. Analyze DNS requests to find suspicious domain names.

6. Examine protocols such as DNS, HTTP, HTTPS, TCP, and UDP.

7. Look for repeated connections to the same external IP/domain.

8. Check for unusual ports or unexpected protocols.

9. Record suspicious IP addresses, domains, ports, and packet counts.

10. Use the observations to determine the malware's possible network behavior.

Input
Export packet information from Wireshark as CSV. For example:
Destination,Destination Port,Protocol
192.168.1.20,53,DNS
8.8.8.8,53,DNS
192.168.1.20,443,TCP
45.67.89.10,443,TCP
45.67.89.10,443,TCP
45.67.89.10,8080,TCP



 Output
=== NETWORK BEHAVIOR ANALYSIS ===

45.67.89.10 -> 3 packets
192.168.1.20 -> 2 packets
8.8.8.8 -> 1 packets

Top Destination Ports:
443 -> 3 packets
53 -> 2 packets
8080 -> 1 packets

Protocols Used:
