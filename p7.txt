Aim
To perform static malware analysis by extracting file hashes, examining file metadata and scanning for embedded text strings (such as IP addresses, domains, or functions) without executing the code. 
Algorithm
1.Start the terminal
2.Set the filenames for the target sample (TARGET) and the output file (LOG_FILE).
3.Check if the target file exists; if missing, create a mock binary file containing sample indicators.
4.Open the target file in binary read mode and store its complete byte data.
5.Pass the file bytes through the MD5 hashing algorithm to generate a unique 32-character fingerprint.
6.Pass the file bytes through the SHA-256 algorithm to generate a highly secure 64-character fingerprint.
7.Use regular expressions to scan the file bytes for sequences of 4 or more printable ASCII characters.
8.Convert the discovered raw byte sequences into readable, plain text string data.
9.Write the file size, calculated hashes, and extracted text strings into a structured text report.
10.end the program
